# 01 产品原型设计 · Android

产品名：**对译 Duiyi**
形态：Android 手机原生 App，竖屏锁定
定位：多语言现场沟通平台。面对面、同声传译、会议记录、任务历史是四个模块，不是四个 App。

可交互界面：[`../prototype/platform.html`](../prototype/platform.html)
架构：[`02-architecture.md`](02-architecture.md)

本文只写 **Android 上怎么呈现同一套产品**。任务怎么开始 / 结束、字幕打到哪一侧、同传禁外放，三端不得分叉。

## 1. 产品承诺

用户打开对译，先选「此刻要做什么」，再进入该模块干活。

| 模块 | 谁在用 | 屏幕 | 核心产出 |
| --- | --- | --- | --- |
| 面对面 | 两人隔桌 | 上下对半，上屏 180° | 双方各自看到译文 |
| 同声传译 | 一个人听现场 | 单栏正字 | 实时译文，可选耳机读出 |
| 会议记录 | 一个人记一场会 | 单栏正字，全文稿 | 完整文字稿 + 会后总结 |
| 任务历史 | 回看已结束的工作 | 列表 + 详情 | 总结、导出分享 |

三条共用：语种、权限、本机听写 / 翻译、任务与历史、总结与导出。

原则：

1. **操作简单**：每个模块主路径不超过「新任务 → 开始听 → 结束」。
2. **界面统一**：画布 `#12141A`，正文 `#F4EFE6`，主操作金 `#E8B86D`。用 Compose 系统对话框 / 分享面板，不要换一套 Material 默认紫。
3. **可扩展**：加一种语言或一个新模块，不改另外两个模块的 ViewModel。
4. **本机优先**：听写、翻译、任务都留在手机；总结能用 Gemini Nano 就用，不能用就说清楚，并允许导出。

Android 特有约束（产品必须提前说）：

- 面对面**不能保证**像 iOS 那样两路识别同时跑。语种切换靠系统端侧「多语种识别 + 语言检测」，插话间隙小于约 400 ms 时可能丢半句。界面不假装「双引擎」。
- 部分机型没有端侧识别（`isOnDeviceRecognitionAvailable == false`）。引导页直接说「这台手机还不能离线听写」，不要进主界面空转，也不要默默改走云识别。

## 2. 信息架构

```
启动
  ├─ 首次：欢迎 → 我看的语言 → 麦克风权限 → 下载翻译模型 → 首页
  └─ 再次：首页

首页
  ├─ 面对面
  ├─ 同声传译
  ├─ 会议记录
  ├─ 任务历史
  └─ 设置（语言包、字号、权限）

面对面 / 同声传译 / 会议记录
  ├─ 无任务：大按钮「新任务」
  ├─ 进行中：开始 / 暂停 + 「结束任务」
  ├─ 结束后：回首页或看刚保存的记录
  └─ 设置卡片（本模块语言、字号，不离开现场）

任务历史
  ├─ 按时间倒序，可按模块筛选
  └─ 一条记录：回看字幕 / 总结 / 导出分享 / 删除
```

系统返回：预测性返回（Predictive Back）从模块回到首页，从详情回到历史。面对面进行中返回要二次确认「是否结束任务」——返回不等于暂停。

## 3. 任务生命周期

与 iOS 完全相同。任务是一次完整工作，不是一次点按听写。

```
未开始 ──新任务──► 进行中 ──结束任务──► 已保存（历史）
              │                    ▲
              └──暂停听写（任务仍在）─┘
```

| 动作 | 行为 |
| --- | --- |
| **新任务** | 若已有进行中的任务，先确认是否结束并保存，再开新的。清空现场字幕，记下开始时间、模块、语种。 |
| **开始 / 暂停** | 只控制麦克风。暂停不等于结束。 |
| **结束任务** | 停听写、归档字幕、写入本地历史。可选立刻打开总结。 |
| **进模块但没点新任务** | 不写历史。中间钮不可点。 |
| **切模块 / 进后台 / 熄屏** | 进行中的任务保持「进行中」，听写暂停。不做前台服务续听。 |
| **杀进程** | 下次打开：未正常结束的任务标为「未结束」，可继续或结束保存。 |

标题自动生成：

- 面对面：`8月30日 面对面 · 中文 ↔ 英语`
- 同声传译：`8月30日 同声传译 · 英语 → 中文`
- 会议记录：`8月30日 会议 · 中文`；有内容后可用首句前 16 字作副标题

## 4. 各模块主界面

### 4.1 首页

大卡片，一块模块一件事，不要宫格图标墙。顶部右侧齿轮进设置。

若有未结束任务，卡片上方先列「未结束的任务」，点进对应模块继续。

Android 视觉：状态栏深色、导航栏深色、无底部 Tab。四个入口全在首页滚动区，避免和「中间听写大钮」抢位置。

### 4.2 面对面

两人隔桌，手机平放，竖屏锁定，**不以重力翻转布局**。

```
┌ 面对面                          历史  ┐
│  进行中 · 10:24                     │
│  [新任务]              [结束任务]    │
│  ──────── 上半屏字幕（180°）──────    │
│              ● 聆听中               │
│  ──────── 下半屏字幕 ────────        │
└─────────────────────────────────────┘
```

字幕路由（语种当键，不靠说话人分离）：

| 识别到的语种 | 用户屏（下，正字） | 对方屏（上，倒字） |
| --- | --- | --- |
| = 用户语言 | 轻提示：正在说… | **对方语言的译文** |
| = 对方语言 | **用户语言的译文** | 轻提示：正在说… |

倒字：整块 Compose 容器 `rotate(180f)`，不要逐字镜像。面对面倒字区域的按钮只放在下半屏用户侧。

无任务时中间钮不可点。新任务后可按偏好自动开听（与 iOS 面对面一致）。

### 4.3 同声传译

一个人听现场。手机朝向自己，单栏正字。

- 方向：他说的语言 → 我听的语言，必须不同。
- 识别只跑源语言。
- 读出默认关。打开时：已接有线 / 蓝牙耳机或听筒 → 朗读；仅扬声器 → 禁止，提示「戴上耳机再读出」。
- **新任务不自动开听**。

### 4.4 会议记录

只选一种记录语言。正文完整稿，按句追加，同一句修订合并。不读出、不存音频。结束进入本条记录：全文 + 总结 + 导出。

超 2 万字提示「结束并新开一条」。

### 4.5 任务历史

一张列表，按模块色点筛选。左滑删除走 `SwipeToDismiss` + 确认对话框。点进去只读回看。

空状态：`还没有任务。从首页开一个新任务。`

## 5. 总结与导出

总结挂在**一条已结束的任务**上。

| 设备 | 点「总结」时 |
| --- | --- |
| AICore + Gemini Nano 可用 | 本机生成摘要，标明「由 Gemini Nano 在本机生成」 |
| 支持但模型未就绪 / 未下载 | 说明正在准备，稍后再试；仍可导出 |
| **不支持（多数非旗舰）** | **直接说这台手机不能在本机生成摘要**，不要写「打开即可」 |

导出 UTF-8 `.txt`，走系统分享面板（`Intent.ACTION_SEND`），不深链微信 / 元宝。

```
对译 · 同声传译
2026-08-30 10:18–10:44
英语 → 中文

文字稿
…

总结
…（若已生成）
```

## 6. 语言与权限

现场语种与界面语种分开。不可用的听写 / 翻译 / 朗读在选语种网格里灰掉，说明「这台手机还没有这个语言模型」。

权限只申请 `RECORD_AUDIO`。不申请「始终录音」、不申请通知（v1 不做前台服务）、不申请通讯录。

引导文案直说：「只在本机转写和翻译，用于当面字幕。不会上传你的声音。」

## 7. 界面原则（Android）

- 色板沿用 iOS Tokens，不要换成 Material 默认 `primary`。
- 破坏性操作：`AlertDialog` / `ModalBottomSheet` 确认。结束任务：`结束并保存这条记录？`
- 分享：系统 Sharesheet。
- 动态字体：首页、历史、设置跟随系统；取景式字幕板有字号档，封顶避免倒字溢出。
- 无障碍：`contentDescription` 覆盖模块名、新任务 / 结束、听写钮。TalkBack 下倒字容器要标「给对方看的字幕」。
- 预测性返回：模块页启用；听写中返回走确认，不直接 pop。
- 保持唤醒：`FLAG_KEEP_SCREEN_ON` 仅在 listening。
- 明确不做：横屏、折叠屏双屏同时听写、平板分栏 v1、桌面小部件。

---

## 8. 明确不做（本阶段）

- 不把面对面和同声传译合成一个 ViewModel。
- 不存录音、不上云、不做账号、不做前台服务后台听写。
- 不在 App 内嵌微信 / 元宝 SDK。
- 不做说话人分离。
- 不在会议记录里做实时同传朗读。
- 不把云端 Speech-to-Text 当作「离线不可用时的静默降级」。
